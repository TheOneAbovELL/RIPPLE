## Summary

  briefing, shared; summarises / inferred_from / briefing_from = depends_on,

  (default jobs, so smoke and v0 files and hashes are unchanged); `validate_scenario`
  reports an unknown domain or a link type the domain does not know.
- **Tracks** (ADR-0101): `bench/tracks.py` (v0 split rule, proved equal to
  `bench.generate`; test-only mode; manifests labelled `content: synthetic`; curated
  real-story loading with validated provenance), `bench/generate_news.py`,
  `bench/generate_finance.py`, data in `bench/data/news_v1/` and
  `bench/data/finance_v1/`: 35 scenarios each (5 personas x 7 families), `--check`.
- **Finance C5 pairs** (ADR-0102): `bench/data/finance_v1/pairs.jsonl`, all
  `Split.TEST`, one per distinct text pair; reversed edges and same-attribute facts
  kept as noted negatives; indirect dependencies left out.
- **STALE** (ADR-0103): `bench/stale.py` loader from `RIPPLE_STALE_PATH`
  (ConfigurationError naming it when unset or missing), strict declared shape,
  `python -m bench.stale` summary; the docs/04 mapping question is **left open**
  (the release format could not be read offline); tiny hand-written fixture.
- **check_everything order** (ADR-0104): `parents_first` in `bench/strategies.py`, so
  the ask-family result no longer depends on alias spelling. v0 unchanged (see below).
- **bench.run**: suites `news_v1`, `finance_v1`; `--split curated`; finance refuses
  `--split train`; an empty selection is refused instead of writing a "passing" folder;
  report.md carries a "Data: synthetic" line; config.json adds `source_sha256` (code
  hash, since every run's git sha is "uncommitted").
Not touched: core, bench/linkpairs.py, bench/metrics.py bodies, bench/generate.py,
jobs data, tests/scenarios, any coordinator-owned file. Nothing committed.
