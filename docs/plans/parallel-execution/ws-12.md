## Caddy / deployment notes for the coordinator (WS-0)
1. **CSP blocker.** `infra/Caddyfile` sets `default-src 'self'` with no `script-src`.
   The App Router export emits inline bootstrap scripts (`self.__next_f.push(...)`,
   the Turbopack chunk list), so the page would render the pre-rendered shell and
   never hydrate. Needed: `script-src 'self' 'unsafe-inline'` (a static file cannot
   carry a per-request nonce; per-build hashes would need templating the Caddyfile),
   and while there `object-src 'none'; base-uri 'self'; frame-ancestors 'none'`.
   `img-src 'self' data:` and `style-src 'self' 'unsafe-inline'` already suffice;
   `connect-src 'self'` is right because the client calls `/api` on the same origin.
2. **Static path.** `npm run build` writes `apps/web/out/` (about 1.2 MB). The deploy
   step copies it to `infra/web-dist`, mounted at `/srv/web` by
   `infra/docker-compose.prod.yml`; the existing `try_files {path} {path}/ /index.html`
   serves `memories/index.html` for `/memories/` and `/memories/detail/index.html` for
   `/memories/detail/?id=…` (the id is a query string, ADR-0086). `trailingSlash: true`
   matches that layout.
3. **Prefetch 404s.** Next 16 prefetches `/<route>/__next.<route>.__PAGE__.txt`, which
   the export does not emit; navigation still works (it falls back to the `_tree.txt`
   that does exist). Expect these in the access log; a `handle` that answers 204 for
   `*.__PAGE__.txt` would quiet it.
4. **Build in CI.** Suggested job inside apps/web: `npm ci && npm run lint && npm test
   && npm run build`, then upload `out/` as the artefact the image or deploy step
   copies. Node 22 (22.22+ removes the engine warnings).

## Contract change requests
1. **OpenAPI drift test** (tests/api, coordinator-owned). Add
   `tests/api/test_openapi_snapshot.py`:
   ```python
   import json
   from pathlib import Path

   from tests.api.harness import Harness

   SNAPSHOT = Path(__file__).resolve().parents[2] / "apps" / "web" / "openapi.json"


   def test_dashboard_openapi_snapshot_matches_the_api() -> None:
       live = Harness.build().app.openapi()
       assert json.loads(SNAPSHOT.read_text(encoding="utf-8")) == live, (
           "apps/web/openapi.json is stale: run the one-liner in apps/web/README.md, "
           "then `npm run gen:api` and `npm run lint` inside apps/web"
       )
   ```
   The snapshot is written with `indent=2, sort_keys=True`; equality is on the parsed
   document so formatting cannot fail it.
2. **`EditIn.valid_to`**: the inspector should let a user end a belief's validity when
   editing (FR-12 "edit (content, valid_to)"); `EditIn` has only `content` and
   `structured` (extra="forbid"). Until then the form shows `valid_to` read-only.
3. **`GET /graph`** (ADR-0087): `{nodes: [MemoryOut], links: [Link]}` for the user's
   visible memories, replacing N+1 detail calls on the map page.
4. **`Memory.id` required in the schema**: `id` has a default factory so FastAPI
   emits it as optional; the UI carries `id ?? ""` fallbacks that a `required` marker
   (or `Field(..., json_schema_extra)`) would remove.
5. **Kind / attribute vocabulary from the API**: the kind filter and the map's "skill"
   category hardcode `src/ripple/domains/jobs/vocabulary.py` values in
   `apps/web/src/features/domain/jobs.ts`. A small `GET /vocabulary` (kinds, profile
   attributes) would keep the dashboard domain-agnostic.
6. **CORS for local development**: `next dev` on :3000 against uvicorn on :8000 needs
   `CORSMiddleware` for `http://localhost:3000` in development only (the production
   path is same-origin through Caddy). Without it, develop against the static export
   served behind the API as the live check did.
