## What was built
- **Registry** (126 macros): scripted-oracle sanity counts `oracle.v0.<strategy>.*`
  (resolver must start with "scripted oracle"), smoke counts, headline memory metrics
  `mem.<strategy>.*` (ADR-0063 keys, v0 split `test`, mean over ≥3 seeds), hypothesis
  macros `h1.*`–`h4.*` (derived, with the config fields each comparison may differ in),
  linker macros `link.<linker>.<track>.*` (F1, typed F1, scenario-provenance F1, strict
  split, cost), hand-check agreement `handcheck.jobs_v0.*`, ablations `ablation.*`,
  pilot metrics `pilot.*`. Three figures as data (CSV, pgfplots `.dat`, SVG).
- **Renderer** fails closed: clean commit for every macro (`--draft` relaxes this for
  non-headline macros, writes generated/draft/ marked DRAFT); complete runs; pinned
  models and prompt versions when a model is used; whole-config consistency for means;
  a newer failing run or a disagreeing repeat refuses the macro; derived macros and
  figures refuse runs that differ beyond the compared fields; ≥3 run seeds for
  headline. `--check` (stale generated files) and `--strict` (camera-ready gate).
- **Outlines** (docs/paper/): paper and thesis section by section mapped to C1–C4,
  H1–H4, baselines, ablations, pilot metrics; LaTeX commands and labels in comments;
  numbers only as `{{num:key}}`; strict I8 mode (any digit is a claim) applies there.
- **I8 check** (paper/i8.py + `test_invariant_I8_every_result_number_in_docs_traces_to_results`
  in tests/paper/test_paper_invariants.py): see ADR-0111 for what counts as a claim
  and the acceptance order (macro, citation of a results/ folder in the same block,
  allow-list category, allow-list text with line context, known violation).

## Open problems

  (e.g. results table cells) and numbers in words are not seen (ADR-0111).
- Nothing renders until runs are committed; the author's first commit plus a re-run of
  the baselines makes the oracle counts render.
- Whether docs/04 "three seeds" means run seeds or generator seeds is open; a
  deterministic harness (oracle resolver, rule linker) meets the run-seed gate
  trivially.
- The pin check accepts model aliases (`claude-sonnet-5-5`); only served model ids
  recorded by the producers make "pinned" mean a snapshot.
- Files I could not delete (permission): docs/paper/generated/draft/ is written by
  `--draft`; keep it out of git.
