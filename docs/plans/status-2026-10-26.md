## 4. The honest totals

- **Of the 38 roadmap line items, about 26 are written as code** (a hand count, not a measurement). The
  collaborator's share of those is complete except Scout reconciliation and the wave-B
  research items. The remaining 12 split into: 3 author-owned bodies, 5 wave-B
  workstreams, 2 pilot items that need real people, 2 write-up items that need numbers.
- **Of the production plan, wave A was built but not yet integrated before C3**:
  five workstreams wrote their code and tests; the coordinator has applied none of
  their contract requests yet, one (WS-13) has no records, and one (WS-9) was cut off
  mid-review.
- **Verified against real services: nothing.** Every green test uses fakes. Postgres,
  Redis, the Anthropic API, Telegram, Docker and CI have never been exercised from this
  machine because the author has not yet made the first commit, added a remote,
  installed Docker or set a key. This is the single largest risk: 1258 passing tests
  prove the design, not the deployment.
- **Calendar:** the roadmap placed Phase 0 in Oct–Nov 2026 and Phase 4 in mid-2027.
  Code-wise the project is at Phase 3–4 after seven working days. The critical path is
  no longer collaborator throughput; it is the author's list below.
