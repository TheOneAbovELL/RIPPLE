# ADR-0006: Expose memory tools over MCP
Status: Accepted · Date: 2026-10-19

## Context
Ripple should be usable by agents other than our own.

## Decision
An MCP server exposes search, save, update, forget and explain. Our own agents call Python
APIs directly.

## Alternatives considered
- REST only — fine for the web app, but not the standard for agent tools.

## Consequences
Invariants and auth must be enforced at the server boundary.

## Revisit if
The MCP spec changes in a way that breaks the server.
